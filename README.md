# HAH913E-2026-RAPPORTDEPROJET
Analyse de l'activité physique à l'aide de deux accéléromètres AX6

## Présentation du projet

Ce projet a pour objectif d'analyser et de comparer les données d'accélération recueillies à l'aide de deux accéléromètres AX6 lors de différentes conditions de marche.

L'analyse repose notamment sur le calcul de l'ENMO (Euclidean Norm Minus One).

## Organisation du dépôt

- `main.ipynb` : programme principal permettant de réaliser l'ensemble de l'analyse.
- `data` : données enregistrées par les deux accéléromètres AX6.
- `notebooks` : notebooks utilisés lors du développement du projet.
- `results` : résultats et compte rendu du projet.

## Exécution du programme

Les bibliothèques Python nécessaires sont :

- pandas
- numpy
- matplotlib
- scipy

Installez les avec cette commande :
pip install -r requirements.txt

Ouvrir le fichier `main.ipynb` et cliquer sur « Run All » pour exécuter l'ensemble du programme et afficher les résultats.
