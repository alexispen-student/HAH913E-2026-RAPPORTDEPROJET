Données expérimentales

Ce dossier contient les données enregistrées par les deux accéléromètres AX6.

TEST1_AX6.csv : données du premier accéléromètre.

TEST2_AX6.csv : données du second accéléromètre.

Les fichiers contiennent les horodatages et les mesures d'accélération selon les trois axes X, Y et Z.
